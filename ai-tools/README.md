# Git básico

Esta carpeta conserva únicamente la [guía de Git](git-basico.md): versiones, ramas y hooks locales.
La aplicación no necesita frameworks ni skills de IA para ejecutarse o verificarse.

Ejecuta los comandos desde la raíz del proyecto, salvo indicación contraria. Conserva configuraciones y cambios ajenos; una validación local no autoriza push ni operaciones remotas.
